# Python Practice

AI 엔지니어 신입 코딩테스트를 준비하며 **Python 문제를 직접 구현한 코드와 복습 기록**을 관리하는 저장소입니다.

## 학습 목표

- 조건문, 반복문, 리스트, 문자열, 딕셔너리를 활용한 기초 구현
- 프로그래머스 Lv.1 문제를 안정적으로 해결
- 백준 실버 기초 문제에 도전할 수 있는 수준 달성
- 정답 암기보다 **스스로 문제를 읽고 구현하는 능력** 강화

## 학습 방식

1. 먼저 스스로 코드를 작성합니다.
2. 피드백을 받고 필요하면 힌트로 수정합니다.
3. 해결한 코드와 시간·공간복잡도를 기록합니다.
4. 실수한 개념은 다음 학습에서 다시 점검합니다.
